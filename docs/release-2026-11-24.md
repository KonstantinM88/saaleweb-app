## Проверки

После обновления effect последовательно пройдены typecheck и полный lint.
Все 13 newsletter security scenarios повторно прошли с изолированной
PostgreSQL 17, подменёнными SMTP/Siteverify и независимыми Node-процессами.
Реальные письма не отправлялись. Первый запуск теста использовал неверное
имя локальной роли; исправлена команда окружения на `newsletter_test`, код
приложения/схема ради этого не менялись. Тестовый PostgreSQL остановлен.

Обычная production Webpack сборка и принудительная SWC-WASM сборка Next.js
16.4.6 завершились успешно: по 247 страниц. Вывод `next-swc build: wasm build
@next/swc-wasm-nodejs` подтверждает фактический WASM-путь. Существующие
предупреждения Edge Runtime и кеша next-intl не блокировали результат.
Первая сборка до обновления effect была остановлена как неактуальная;
итоговые две сборки выполнены после установки патча.

На готовой WASM-сборке проверены 11 приоритетных страниц: HTTP 200, один H1,
self-canonical, наличие в sitemap и ожидаемые hreflang. У трёх главных один
FAQPage с 28 вопросами, четыре alternate, локализованное сообщение
недоступности подписки и отсутствие newsletter footer form. У четырёх
сохранённых EN/RU услуг корректно только EN/RU/x-default: старые DE-страницы
были объединены ранее и не восстановлены. Sitemap содержит 229 уникальных
канонических URL; API статуса возвращает `enabled=false` и `no-store`.
[HTTP-доказательство](audits/2026-11-24-release-http-local.json).
В первоначальной одноразовой проверке были слишком строгие предположения
о trailing slash главной и наличии удалённых DE alternates; исправлены
проверочные условия, приложение не менялось.

`scripts/check-seo-url-integrity.mjs` повторно прошёл все 18 проверок:
308 → 200 с сохранением query, отсутствие плохого URL в HTML/RSC, четыре
восстановленные ссылки. Тестовый Next PID39124 остановлен, порт 3198 свободен;
временные логи удалены. PostgreSQL PID14200 также остановлен, порт 55439 свободен.

Предыдущие пять HTTP-сценариев и браузерная проверка newsletter DE/EN/RU
сохранены отдельными доказательствами исходного исправления; это не новая
проверка реальной SMTP-доставки. История desktop/mobile проверки редизайна
остаётся в соответствующих отчётах 16–18 ноября.

До staging проверен весь состав изменений: `.env`, `.next`, node_modules,
generated Prisma Client и временный кластер Git игнорирует; совпадений с
секретными значениями локального `.env` в подготовленных текстовых файлах
не обнаружено. Синтетические test credentials относятся только к loopback
фикстурам, а не к production.

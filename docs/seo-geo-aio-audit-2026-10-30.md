# SaaleWeb: полный SEO / GEO / AIO анализ и рекомендации — 30.10.2026

Сайт: https://saaleweb.de/. Приоритет владельца не изменился: сайты для бизнеса в Halle (Saale) и Saalekreis. Документ продолжает [аудит от 02.10](./seo-geo-aio-audit-2026-10-02.md) и [план TOP 10](./seo-top10-roadmap-2026-10-03.md), их не заменяет.

## 1. Вывод

Техническая индексируемость в production **чистая**. Все 231 URL из sitemap отвечают 200 и содержат self-canonical, четыре hreflang, один H1 и валидный JSON-LD. Нет noindex и изображений без alt; неизвестные пути отдают 404, www перенаправляется на основной домен через 308.

Главные риски — структура контента, внутренние ссылки и доступ ботов:

1. **30 шаблонных страниц «город × услуга»** совпадают между собой на **84–86 % по живому тексту**. Для сравнения: настоящие разные страницы, например Webdesign Halle и SEO Halle, совпадают на 25 %. Это doorway-паттерн по политике Google.
2. **18 URL старых CMS-услуг — сироты**: в sitemap они есть, но ни одна страница сайта на них не ссылается. Это тонкие страницы (280–340 слов против 800–1000 у новых) с тем же намерением, что и новые посадочные.
3. **Слабые внутренние ссылки на коммерческие страницы.** На WordPress Agentur Halle (второй по объёму запрос в GSC) ведут всего 2 внутренние ссылки, на премиальные Beauty и Bau — тоже 2.
4. **Hostinger CDN фильтрует ботов.** Подставные bingbot и GPTBot попеременно получают 403 и 429, в том числе на `robots.txt`. Для GEO (ChatGPT, Copilot) это нужно проверить в первую очередь.
5. **Мало сигналов авторитета:** 2 отзыва Google, нет страницы «О нас», в Organization нет логотипа и адреса, новых статей нет с 30.06.

## 2. Метод и ограничения

| Источник | Что сделано |

Отдельно проверены 404, редиректы, сжатие и ответы на user-agent ботов. Агрегаты сохранены в [`audits/2026-10-30-production-crawl.json`](./audits/2026-10-30-production-crawl.json), тексты страниц не сохранялись. |
| Код | Метаданные, разметка, sitemap и хабы. Сходство кодовых посадочных — в [`audits/2026-10-30-landing-similarity.json`](./audits/2026-10-30-landing-similarity.json). |
| Сходство | Коэффициент Жаккара по 5-словным шинглам видимого текста. Он включает общие блоки (CTA, блок эксперта), поэтому 0,2–0,3 — нормальный фон для разных страниц. |
| Предыдущие аудиты | Данные GSC до 17–19.10 из [сравнения периодов](./search-period-comparison-2026-10-19.md) и [охвата главной](./homepage-reach-audit-2026-10-19.md). |

**Ограничения.**
- GSC, GA4 и БД в этой сессии недоступны: нет секретов. Поэтому показы и клики по конкретным URL до любых объединений нужно выгрузить отдельно.
- PageSpeed API без ключа вернул 429. Производительность по просьбе владельца остаётся на паузе.
- Проверки ботов выполнены подставным user-agent с облачного IP. Они показывают поведение фильтра CDN, а не доказывают блокировку настоящих Bingbot и GPTBot.

## 5. Что уже в порядке

- Self-canonical, четыре hreflang, один H1 на всех 231 URL; sitemap без редиректов и noindex.
- 404 для неизвестных путей; www → основной домен с сохранением query; старый Performance → 308.
- robots: доступ для поисковых и AI-ботов, `/api/` и `/admin/` закрыты; `Host` удалён.
- Видимые прямые ответы, реальные кейсы, блок эксперта и даты проверки; `llms.txt` фактический.
- Изображения с alt; разметка разбирается без ошибок.

## 7. Чего не делать

- Не создавать новые страницы «город × ключевое слово» и варианты написания для существующих владельцев кластеров.
- Не удалять и не перенаправлять страницы без выгрузки GSC.
- Не делать редирект главной и не менять одновременно главную, robots и маршрутизацию.
- Не публиковать числовые результаты кейсов, отзывы или упоминания без доказательств и согласия клиента.
- Не отключать защиту CDN полностью: разрешить нужно только проверенных краулеров.

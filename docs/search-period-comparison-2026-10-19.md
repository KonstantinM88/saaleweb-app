# Сравнение поисковой видимости — 19.10.2026

## Результат

За последнюю полную неделю показы выросли, но за 28 дней охват остаётся ниже предыдущего периода. Улучшение некоторых средних позиций не означает восстановления всего охвата или устойчивого первого места в обычной выдаче Halle.

## Метод

Прямой Search Console API, `https://saaleweb.de/`, поиск `web`, `dataState=final`. Повторная проверка свежести вернула `firstIncompleteDate=2026-10-18`, поэтому последняя полная дата — 17 октября. Суточные даты GSC относятся к Pacific Time. Свежие предварительные данные 18–19 октября исключены.

- Предыдущие семь дней: 04–10.10.2026; последние семь: 11–17.10.2026.
- Предыдущие 28 дней: 23.08–19.09.2026; последние 28: 20.09–17.10.2026.
- Периоды одинаковой длины, не перекрываются внутри каждой пары.
- Основное сравнение ограничено Германией; устройства сравниваются отдельно. Германия не фиксирует город Halle.
- Запросы отфильтрованы по точному совпадению четырёх фраз. Общие итоги получены отдельными запросами без ограничения этими фразами.
- Срезы по страницам и запросам не являются полной суммой итогов ресурса; не следует восстанавливать общий трафик сложением строк. В частности, возвращённые URL-строки не объясняют все клики итогового среза Germany; распределение этих кликов между страницами не установлено.
- Исходные агрегированные ответы: [JSON](audits/2026-10-19-gsc-period-comparison.json).

## Что следует из сравнения

1. **Неделя лучше по показам, месячный охват хуже.** Называть ситуацию полным восстановлением пока рано.
2. **Редкие высокие позиции не равны стабильному ТОП.** Google считает среднюю по зарегистрированным показам; поиск без показа сайта не добавляет низкую позицию в среднее. [Методика Google](https://support.google.com/webmasters/answer/7042828?hl=ru).
3. **Причина ручного расхождения не установлена.** Эти API-срезы не фиксируют город, персональную выдачу или конкретный формат каждого результата; они не воспроизводят независимый замер классической выдачи в Halle.
4. **Ближайший приоритет — охват главной и существующие коммерческие страницы.** Следующее сравнение полных семи дней должно проверить сохранение показов вне однодневного всплеска, клики и появляющиеся URL. Для реального местного ранга нужен повторяемый ручной замер с зафиксированным местоположением и устройством.
5. Не менять robots, редиректы и каноникализацию на основании одних средних позиций. Не создавать отдельные дубли для Webdesign/Webdesigner/Webagentur. Тексты и перелинковку следует менять только после конкретной оценки соответствующей посадочной запросу.

Это анализ, а не публичное обновление. Код, контент сайта и настройки не менялись; повторная отправка URL на индексацию не требуется. JSON проверен; выполнены проверка локального diff и `git diff --check`. Сборка и тесты приложения не требуются для этих локальных документов.

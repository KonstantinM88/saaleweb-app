# Onebbau — дополнение портфолио

## Проверенный источник

Владелец попросил добавить действующий сайт https://www.onebbau.de/.
25.11.2026 сайт открылся по `/de`: Bau- und Handwerksleistungen в Halle
(Saale), переключатель DE/RU, отдельные страницы услуг, галерея, FAQ,
контактная форма, телефон и WhatsApp. В футере есть ссылка на SaaleWeb
как разработчика. Рост трафика, заявок и позиции не измерялись и не обещаются.

## Реализация

Обложка индекса и главного изображения кейса обновлена по запросу владельца: сгенерированный mockup
монитора и смартфона на светлом столе в стиле соседних карточек. Файл
`public/images/cases/onebbau-monitor-phone-v1.webp`, 1536×1024, 106 524 байта.
Использован встроенный imagegen; реальные снимки внутри кейса сохранены.
[Источник, точный промпт и проверка](design/2026-11-25-onebbau-cover.md).

- Шестой проект на главной: краткое описание на DE/EN/RU, ссылка на кейс
  и отдельная ссылка на работающий сайт. Четыре компактные карточки теперь
  образуют две строки по две на широком экране; два существующих крупных
  кейса с обратной связью сохранены.
- Детальная страница `/projekte/onebbau`, `/en/projects/onebbau`,
  `/ru/proekty/onebbau` использует существующий шаблон кейса и его live-site CTA.
  Добавлены собственные описание, деловой фокус и три FAQ на каждом языке.
- Реальные независимые снимки desktop/mobile от 25.11.2026 сохранены
  в галерее. В начале кейса показана та же обложка с монитором и смартфоном,
  что и в индексе: пропорции 3:2 сохраняют устройства целиком. Другие кейсы
  сохраняют прежнее отображение. Изображение Open Graph/CreativeWork теперь
  совпадает с новой обложкой; канонические адреса и sitemap не менялись.
- Оптимизированные WebP: desktop 1432×943 / 77 294 байта,
  mobile 382×827 / 27 038 байт. Снимки получены из браузера при viewport
  1440×1000 и 390×844; размеры экспортированных файлов отличаются от viewport.
- `llms.txt` и `llms-full.txt` дополнены проверяемым проектом. Sitemap объединяет
  существующие CMS-проекты и Onebbau из кода, сохраняя три канонических URL
  с языковыми альтернативами без дубликатов.

## Данные и публикация

После первого этапа владелец не увидел карточку на своём `localhost:3000`.
Причина подтверждена: Onebbau был создан только в изолированной тестовой
базе, а настоящий dev-сервер продолжал читать пять проектов из общей CMS.
Дополнительно главная скрывала Onebbau без CMS-записи. Первый отчёт о
готовности не означал готовность в используемом владельцем окружении.

Исправленная реализация хранит Onebbau в
`src/features/projects/codeProjects.ts`: переводы, данные кейса, изображения,
локализованные категории и URL. Главная показывает карточку без CMS-условия.
Индекс объединяет каталог с прежними DB-проектами, детальная страница
и статические параметры читают каталог, навигация следующего проекта
учитывает Onebbau, sitemap содержит его языковые URL независимо от импорта.
Дубликат этого slug из DB не создаёт вторую карточку или sitemap-запись.
Onebbau управляется исходным кодом; жизненный цикл прежних CMS-проектов
и запрет доступа к неопубликованным CMS-проектам сохранены.

Отдельный upsert-скрипт удалён как ненужный. При публикации достаточно
обычного релиза кода и изображений. Общая база не изменялась, миграции,
правки `.env` и ручной импорт не требуются. Коммит/push/деплой не выполнены.

Исторические результаты изолированной проверки сохранены отдельно;
текущий результат подтверждается проверкой именно `localhost:3000`.

## Проверка

### Исправленный вариант на сервере владельца

- Девять HTTP-проверок главной, индекса и кейса DE/EN/RU на порту 3000:
  все 200, Onebbau виден, карточка в индексе одна. Оба WebP доступны.
- Детальные страницы имеют один H1, self-canonical, четыре hreflang,
  собственный FAQ, обе адаптивные картинки и безопасную ссылку на live-сайт.
- Sitemap на этом же сервере содержит 232 уникальных URL; три URL Onebbau
  присутствуют по одному разу. Это прирост с прежних 229 URL.
- В браузере проверены строительный фильтр и Onebbau в индексе 1440 px,
  видимая карточка и прямая ссылка на главной 1440 px, кейс 390 px с обеими
  загруженными картинками. Горизонтального переполнения нет.
- Финальная последовательность typecheck → lint → Webpack build пройдена.
  Сборка использовала обычную настроенную базу только для чтения и создала
  250 статических страниц: прежние 247 плюс три Onebbau. Прежнее
  предупреждение Edge Runtime сохранено. Сгенерированные HTML Onebbau
  присутствуют для всех трёх языков и включают обе картинки.
- Существующий dev-сервер владельца PID22852 / порт 3000 сохранён.
  Новые серверы и базы для этого исправления не запускались.
  После сборки повторно проверены главная, `/projekte` и кейс на порту 3000:
  все 200, Onebbau присутствует. Собственная вкладка закрыта, viewport
  сброшен. Временных файлов этого исправления не осталось.

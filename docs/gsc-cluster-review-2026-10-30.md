Проверка выполнена напрямую через Search Console API с областью доступа `webmasters.readonly` к `https://saaleweb.de/`. Проверены 57 спорных URL и 48 страниц для сопоставления — всего **105 URL**. Это выборка, а не все страницы сайта.

- 30 страниц «город × услуга»: **109 показов, 0 кликов** за 90 дней; Германия — 22 показа. 17 URL проиндексированы, 13 имеют статус `Crawled - currently not indexed`.
- 18 старых страниц услуг: **6 показов, 0 кликов**; в срезе Германии показов не зарегистрировано. Проиндексированы 10 из 18.
- 9 старых отраслевых страниц: **96 показов, 2 клика**; Германия — 78 показов, 1 клик. Проиндексированы 7 из 9. Эти услуги имеют самостоятельное назначение, эквивалентной премиальной замены нет.
- Все 105 URL сейчас отвечают прямым HTTP 200 и содержат self-canonical. Расхождений выбранного Google canonical с проверяемым URL в возвращённых результатах не найдено.
- Среди 105 результатов URL Inspection: **56 Submitted and indexed**, **49 Crawled - currently not indexed**. В этой выборке нет статусов 404, redirect error или robots-blocked. Это не проверка остальных URL ресурса.

**Массовое удаление или перенаправление всех старых страниц не обосновано.** Для первого небольшого изменения можно подготовить объединение двух немецких CMS-страниц с существующими эквивалентными услугами. Городские страницы требуют отдельного решения о структуре; нынешние данные показывают слабую отдачу, но не доказывают, что именно эти URL вызвали падение сайта.

Публичный код, страницы, redirects, robots и sitemap в рамках этой проверки не изменялись. Предыдущий SEO-патч остаётся локальным; эта выгрузка не измеряет его эффект. Новые результаты сохранены в документации; commit, push, деплой, отправка sitemap и запросы индексации не выполнялись.

### Что делать с городами

У всех пяти немецких региональных страниц Google подтверждает индексацию. Их 90-дневные показатели: Leipzig 33 показа, Merseburg 24, Schkeuditz 21, Delitzsch 53, Saalekreis 47; кликов нет. **Все десять EN/RU региональных страниц этих пяти городов пока имеют статус Crawled - currently not indexed.** Поэтому перенос всех 30 сервисных URL на региональные за один раз особенно рискован: часть индексируемых языковых страниц будет вести на пока не индексируемые цели.

Рекомендация для каждого города — рассмотреть одну содержательную региональную страницу с отдельными блоками Webdesign и SEO, реальной зоной обслуживания, процессом и релевантными примерами. До перенаправления проверить и перенести полезный уникальный материал источников, сохранить ответы на оба намерения и исправить внутреннюю навигацию. Адреса возможных целей:

| Город | DE | EN | RU |
|---|---|---|---|
| Leipzig | `/standorte/leipzig` | `/en/locations/leipzig` | `/ru/goroda/leipzig` |
| Merseburg | `/standorte/merseburg` | `/en/locations/merseburg` | `/ru/goroda/merseburg` |
| Schkeuditz | `/standorte/schkeuditz` | `/en/locations/schkeuditz` | `/ru/goroda/schkeuditz` |
| Delitzsch | `/standorte/delitzsch` | `/en/locations/delitzsch` | `/ru/goroda/delitzsch` |
| Saalekreis | `/standorte/saalekreis` | `/en/locations/saalekreis` | `/ru/goroda/saalekreis` |

Это проект структуры, не выполненная миграция. Число похожих слов из исходного аудита — сигнал для редакторского анализа, а не подтверждённый диагноз spam/doorway со стороны Google. [Правила Google о doorway](https://developers.google.com/search/docs/essentials/spam-policies#doorway-abuse) рассматривают назначение и полезность страниц; ноль кликов сам по себе не является критерием нарушения.

После редакторского сравнения и решения владельца: перенос полезных деталей на цель → постоянный 308 → исключение только источника из sitemap/static params → обновление внутренних ссылок и hreflang → проверка одного перехода 308 → 200. Запись CMS и исходные тексты сохранять, не удалять БД. Группы услуг и CTA должны сохранять доступ к услуге для посетителя.

Постоянные редиректы подходят для объединения эквивалентных страниц; robots, noindex и инструмент удаления URL для такой консолидации не использовать. [Методика canonical Google](https://developers.google.com/search/docs/crawling-indexing/consolidate-duplicate-urls).

Клики пришлись на `/branchen/arztpraxen` и `/branchen/kanzleien`. Эти страницы представляют самостоятельные отрасли, а не эквиваленты Beauty/Bau/Hotel. Усилить содержание и видимую связь с `/branchen`/релевантными услугами. Общая рекомендация исходного аудита «нет трафика — редирект на ближайшую отрасль» для них не принимается.

## Следующая очередь

1. Согласовать и реализовать только DE-пилот из двух эквивалентных пар выше; это отдельное изменение маршрутов. Оценка: вероятно лучше для ясности структуры, с обычным риском колебаний при миграции.
2. Сохранить и усилить Hosting, Digitalberatung, KI-Integration и три отраслевых направления. Добавлять внутренние ссылки по назначению; слабую исходную перелинковку взяли из предоставленного аудита, новый полный link-crawl не выполнялся.
3. По пяти городам принять редакторское решение после подготовки целевых страниц. Не перенаправлять все языки общей волной и не создавать новые варианты «город × ключ».
4. После публикации каждого пакета проверять live-ответы, актуальный sitemap и даты повторного обхода Google; измерять следующее полное 28-дневное окно. Сохранение нулевого трафика не докажет пользу, рост нескольких показов не докажет причинность.
